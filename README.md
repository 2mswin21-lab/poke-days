# POKE DAYS

Supabase에 저장된 데모 상품을 보여주는 포켓몬 굿즈샵입니다. 실제 판매, 주문 및 결제 기능은 제공하지 않습니다. 장바구니는 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 열어주세요. `.env.local`에 Supabase 프로젝트 URL과 공개 키가 설정되어 있습니다. 다른 환경에서는 `.env.example`을 복사해 입력하세요. 공개 키는 클라이언트에서 사용되며 상품 테이블은 RLS를 통해 읽기만 허용합니다.

상품 이미지에는 PokeAPI의 공식 아트워크를 사용합니다. 제품 사진이 아닌 캐릭터 예시 이미지이며, 포켓몬 관련 권리는 각 권리자에게 있습니다.
